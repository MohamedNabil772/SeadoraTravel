# Seadora Travel Design Tokens

This document outlines the shared design foundation for Seadora Travel (Website and Admin Panel).

## Colors

| Token | Variable | Value | Description |
|-------|----------|-------|-------------|
| **Sea** | `--sea` | `#0a5c8a` | Primary Brand Color |
| **Sea Light** | `--sea-light` | `#1a8bc4` | Accent Sea Color |
| **Sea Deep** | `--sea-deep` | `#063a5c` | Deep Water / Hero Gradient |
| **Sun** | `--sun` | `#e8820a` | Primary Accent / Call to Action |
| **Sun Light** | `--sun-light` | `#f5a435` | Glow / Hover Accent |
| **Sun Pale** | `--sun-pale` | `#fdf3e0` | Light Background Accent |
| **Grass** | `--grass` | `#2e7d4f` | Nature / Organic Accent |
| **Grass Light** | `--grass-light` | `#4caf78` | Light Nature Accent |
| **Gold** | `--gold` | `#c9a84c` | Luxury / Heritage Accent |
| **Cream** | `--cream` | `#faf7f2` | Primary Background |
| **Dark** | `--dark` | `#0d1f2d` | Text / Dark Sections |
| **Text** | `--text` | `#2a3f4f` | Body Text Color |
| **Muted** | `--muted` | `#6b8a9a` | Secondary Text / Muted Elements |
| **White** | `--white` | `#ffffff` | Absolute White |

## Typography

| Font Family | Usage |
|-------------|-------|
| **Playfair Display** | Headings, Serif, Luxury feel |
| **Cormorant Garamond** | Subheadings, Italicized text, Elegant Serif |
| **Jost** | Body text, UI elements, Modern Sans-Serif |

## Gradients

- **Logo/CTA:** `linear-gradient(135deg, var(--sun), var(--sun-light))`
- **Primary Button:** `linear-gradient(135deg, var(--sun), #f59c20)`
- **Hero Background:** `linear-gradient(160deg, var(--sea-deep) 0%, var(--sea) 40%, #1a6e8a 70%, #0d4d3a 100%)`
- **Booking Button:** `linear-gradient(135deg, var(--sea), var(--sea-light))`
